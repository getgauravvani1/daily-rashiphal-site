Privacy Policy

Last updated: 15-Sep-2026

Daily Rashiphal ("this tool") is a personal, single-user automation script owned and operated solely by its developer. It is not a public product, is not distributed to other users, and does not offer any service to third parties.

What access this tool requests

This tool requests the https://www.googleapis.com/auth/youtube.upload scope from Google, solely to upload video files to one specific YouTube channel owned by the developer. It does not request access to Gmail, Drive, Contacts, or any other Google data.

What data is collected or stored

This tool does not collect, store, sell, or share any personal data belonging to other individuals. The only credential involved is an OAuth access/refresh token, which is generated by Google and stored locally, in a file on the developer's own computer. It is never transmitted to any server other than Google's own OAuth and YouTube Data API endpoints.

How the access is used

The stored token is used exclusively to authenticate video upload requests to the YouTube Data API, initiated locally by the developer running this tool on their own machine. No automated or third-party access to the account is granted beyond this single upload function.

Data retention and revocation

The token remains valid until the developer revokes it. It can be revoked at any time from the Google Account's third-party access settings , which immediately stops this tool from being able to upload further videos.
