Daily Rashiphal

Daily Rashiphal is a small personal automation tool that generates daily Hindi horoscope videos and uploads them to a single YouTube channel using the YouTube Data API.

It is a private, single-user script — not a public product or service, and it is not distributed to or used by anyone other than its owner/operator.

See the Privacy Policy for details on how this tool uses Google account access.
